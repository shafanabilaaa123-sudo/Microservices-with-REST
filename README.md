# Praktikum Monolith & Microservices

Repository ini berisi kode program untuk tugas praktikum mata kuliah **Paradigma Sistem**.

---

## 🛠️️ Prasyarat (Prerequisites)

Sebelum menjalankan proyek ini, pastikan perangkat Anda telah terinstal software berikut:
* **Node.js** (Versi 18 LTS atau lebih baru) & **npm** (atau sesuaikan dengan stack kamu: Python / PHP / Java)
* **Git**

---

## 🚀 Langkah-Langkah Menjalankan Proyek

Ikuti langkah-langkah di bawah ini untuk menjalankan proyek di lingkungan lokal:

### 1. Clone Repository
Buka terminal / Command Prompt, lalu jalankan perintah:
```bash
git clone [https://github.com/shafanabilaaa123-sudo/Microservices-with-REST.git](https://github.com/shafanabilaaa123-sudo/Microservices-with-REST.git)
cd Microservices-with-REST
